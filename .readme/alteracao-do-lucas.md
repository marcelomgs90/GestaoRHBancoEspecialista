# Branch: alteracao-do-lucas

## Objetivo
Branch acumuladora das alteracoes solicitadas por Lucas.

## Regra de trabalho
- Cada nova feature deve nascer em uma branch propria a partir da `main`.
- Cada feature deve ter seu proprio arquivo em `.readme/` descrevendo objetivo, regras e validacoes.
- Depois de validada, a feature deve ser mergeada nesta branch `alteracao-do-lucas`.
- Esta branch deve conter a soma das alteracoes aprovadas, sem substituir as branches individuais.
